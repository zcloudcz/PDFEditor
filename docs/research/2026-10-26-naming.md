# Product naming research

Research date: 2026-10-26. Recommendation: **ZCLOUD PDF Editor**, short navigation label **PDF Editor** inside the ZCLOUD site. This is a recommendation, not a final naming decision or trademark clearance.

| Criterion | Z PDF Editor | ZCLOUD PDF Editor |
| --- | --- | --- |
| Immediate meaning | Clear PDF function, weak identity from one letter | Clear PDF function and parent identity |
| Existing near matches | Strong: several products use zPDF | Exact editor phrase did not surface in this search; ZCloud itself has many uses |
| Spoken/search recall | Spacing disappears; users may search ZPDF | Longer but more specific query |
| Brand portfolio | Connection to ZCLOUD is implicit | Explicit connection to the user's existing portfolio |
| Privacy message | Neutral | Cloud can suggest uploading; explicitly explain local processing |
| Recommendation | Avoid as standalone brand | Better of the two candidates |

## Evidence

- [zpdf browser editor](https://zpdf.app/en/tools/edit-pdf/) offers online markup and PDF tools under the zpdf name. This is a direct category overlap.
- [zPDF—Free Simple PDF Editor, Chrome Web Store](https://chromewebstore.google.com/detail/zpdf%E2%80%94free-simple-pdf-edit/doffikcfjhomobheencdngekojmmabdn) is offered by Zenqlo and also targets browser/offline editing.
- [Menke Technologies project listing](https://menketechnologies.github.io/projects.html) lists another zpdf desktop editor. Its claims were not independently benchmarked; its existence is relevant to naming.
- [Zettabyte zCLOUD](https://www.zettabyte.com/products/zcloud/) and [Zuri zCloud](https://www.zuritechnologies.com/our-services/it-infrastructure-services/zcloud/) show that ZCloud is not globally unique in software/cloud services. They do not establish a conflict with the proposed editor name by themselves.

Searches included exact quoted names, ZPDF/editor variants and ZCLOUD/PDF combinations. No exact competing ZCLOUD PDF Editor product was identified in these results. Absence from results does not establish availability. Trademark registries, domains, app-store handles and visual marks have not been cleared. zcloud.cz could not be read by the web tool; no new ownership/availability conclusion was drawn.

## Proposed usage

- Product heading and browser title: ZCLOUD PDF Editor.
- Czech description: „Úpravy PDF přímo v prohlížeči.“
- Privacy statement, once network-tested: „Dokumenty zůstávají na vašem zařízení.“
- Suggested location: a PDF section/subdomain of the existing ZCLOUD domain; no DNS or publication performed.
- Source/package slug: zcloud-pdf-editor; no new repository or package registered.
- Upstream authorship remains in accessible license/source information, separate from the product logo.

The local preview keeps the name in one configuration value so the user's final choice is inexpensive to apply.
